# Frontend Integration Guide

## Quick Start

### 1. Environment Setup

Create a `.env` file in your frontend project:

```env
# API Configuration
REACT_APP_API_URL=http://localhost:5000/api
# or for Next.js
NEXT_PUBLIC_API_URL=http://localhost:5000/api
# or for Vue
VUE_APP_API_URL=http://localhost:5000/api
```
